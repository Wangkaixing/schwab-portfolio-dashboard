# Schwab Portfolio Dashboard

本地运行的嘉信交易记录分析看板，用于根据交易 JSON 计算当前持仓、真实现金成本、FIFO 已实现盈亏、产业分布与资金活动。

## 解决的问题

- **税务成本不等于实际投入**：嘉信显示的持仓成本可能包含 wash sale（洗售）产生的税务成本调整。这个数字适合税务申报，却不方便回答“当前剩余持仓实际投入了多少现金、真实买入均价是多少”。本看板依据每笔交易的实际金额还原现金成本，并按 FIFO 扣除已经卖出的批次，不把 wash sale 调增计入真实现金成本。
- **跨期交易难以连续管理**：单次导出的 JSON 往往只覆盖部分日期。本看板支持将多份重叠区间的交易记录取并集，在避免重复记录的同时持续维护完整历史。
- **原始流水不便于复盘**：将分散的买入、卖出和入金记录整理为当前持仓、现金均价、产业暴露、FIFO 已实现现金盈亏和资金活动趋势。
- **展示时容易泄露隐私**：可以一键隐藏金额与证券数量，脱敏状态也会应用到页面 PDF，便于截图、演示或分享分析结果。
- **个人数据不必上传服务器**：交易数据保存在当前浏览器本地，可自行导入、更新、导出和清空；项目本身不需要部署到公网。

> “真实现金成本”用于个人交易复盘，与券商提供的税务成本基础用途不同，不能替代 1099-B 等正式税务文件或专业税务建议。

## 本地启动

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

随后打开 `http://127.0.0.1:3000`。macOS 和 Windows 用户也可以直接使用仓库内的一键启动脚本。

## 数据隐私

交易数据仅保存在当前浏览器的本地存储中，不会提交到本仓库。请通过页面中的“更新 JSON”导入交易数据，并使用“导出 JSON”迁移或备份维护数据。

仓库已忽略本地交易导出文件。提交代码前仍建议检查暂存内容，避免意外公开个人交易记录。
